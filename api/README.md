# HzkMacros Module API v4

Project website: https://hzkmacros.com

This directory contains only the public Java contract required to compile third-party HzkMacros modules:

- `hzkmacros-module-api-4.0.jar` — use as `compileOnly`;
- `hzkmacros-module-api-4.0-sources.jar` — public API source for IDE navigation;
- `hzkmacros-module-api-4.0-javadoc.jar` — generated public Javadocs.

The proprietary HzkMacros core implementation is not part of these artifacts.
